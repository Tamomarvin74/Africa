# 🦓 Africa - Wildlife Discovery App 
A beautiful SwiftUI app to explore the fascinating wildlife of Africa, featuring animals, national parks, and videos. 🌍  
## ✨ Features
🐆 Animal Gallery - Browse through a collection of African animals with stunning images

🎬 Video Library - Watch videos of animals in their natural habitat

🗺️ Interactive Map - Explore the national parks of Africa with an interactive map

🔄 Grid and List Views - Switch between grid and list layouts for browsing animals

📱 Modern UI - Beautiful SwiftUI interface with smooth animations  
## 🎮 How to Use  
Browse Animals 🦁 - Tap on the Browse tab to see animals. Switch between grid and list views

Watch Videos 🎥 - Tap on the Watch tab to view animal videos

Explore Map 🗺️ - Tap on Locations to see interactive map of national parks

Gallery 🖼️ - Tap on Gallery to see animal images with adjustable grid layout  
## 💻 Technical Features  
🎨 SwiftUI - Modern declarative UI framework

📊 JSON Data - Custom Bundle extension for loading data

🗺️ MapKit - Interactive maps with custom annotations

🎬 AVKit - Smooth video playback

✨ Custom Animations - Beautiful transitions and motion effects
